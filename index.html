재난경보 관제 데모

재난문자 발송과 민방공 경보 발령 흐름을 재현합니다. 연동 탭의 QR로 다른 화면을 열면 이 화면에서 보낸 경보가 실시간으로 반영됩니다.

문자 발송 0
경보 발령 0

1. 문자 종류 선택

위급재난문자·긴급재난문자는 연동된 폰 화면에서 알림음이 함께 울립니다.

2. 대상 지역 선택

여러 지역을 함께 선택할 수 있습니다.

3. 문자 내용 작성

0 / 200자

폰 화면 연동

QR을 다른 기기 카메라로 스캔하면 같은 사이트가 폰 화면 모드로 열립니다. 이 화면에서 발송·발령하면 열려있는 폰 화면에 실시간으로 반영됩니다.

대한민국 경보 체계 요약

분야마다 서로 다른 단계 체계를 사용합니다. 공개 자료를 바탕으로 한 요약이며, 세부 발령 기준·비공개 절차까지 전부 담고 있지는 않습니다.
